# Designing an ASIC from scratch
Designing an ASIC from scratch isn't a common task; it may seem like an \"engineer's thing\", but it's actually much more accessible than it seems.
In this guide, I'll explain how I designed my first ASIC, so you can do it too.

![ASILUC 2D Image](/projects/ASILUCPreview.png)

## Why design an ASIC
Have you ever whised to have a special chip that performs a specific operation for one of your projects?
If the answer is yes, designing an ASIC is the answer!
In fact, an ASIC is an *Application Specific Integrated Circuit*, this mean that is literally a chip designed to do one thing.

Designing an ASIC may not only be fun and educative, but also a real challenge!
You have to handle binary operations, logic functions, phisical connection between inputs, modules and outputs, and much more!

## The idea
I started designing ASICs with a really easy project: develop one to works as an ALU!

I'm joking, it wasn't easy, but it wouldn't be funny if i started from an ASIC that made a led blink or something similar.

The goal was to design an ASIC *from skatch* in **Verilog HDL** (for the ones who don't know, an HDL is an *Hardware Description Language*).

My first ASIC project is ASILUC: a simple ALU that may fit in a calculator.
The ASILUC perform 16 bit operations from two 8 bit numbers given in input.
It supports some elementar commands like `SUM`, `SUB`, `MUL` and `DIV`.

I recommand starting (whether is your first project) from just a few simple functions, and then add other functions.

## Where to start
If you are still reading, this means that you are interested to learn how to design you first ASIC!

First of all, you'll need some basics of electronics, in particular about digital signals and logic gates.

Once you have this basics, you can start by learning an HDL.
I recommand Verilog HDL, but you can use others too!

To learn Verilog, I've learned by doing the exercises on [https://hdlbits.01xz.net/wiki/Problem_sets#Verilog_Language](https://hdlbits.01xz.net/wiki/Problem_sets#Verilog_Language).
I strongly recommand to take confidence with those exercises before to continue.

It's now time to create the GitHub repo.
I reccomand using [TinyTapeout/ttgf-verilog-template](https://github.com/TinyTapeout/ttgf-verilog-template) as template.

Now you should setup the environment.
I reccomand installing [yosyshq/oss-cad-suite-build](https://github.com/yosyshq/oss-cad-suite-build) for the compilation and the simulation tools.

Now you are ready to start designing your first ASIC!

## Architecture and Design
Ok, now you should have learned how Verilog works and how to develop with it.

A good project should have a simple and clear main file and a lot of little modules made to be used inside the main or in other modules.

The main file in the *TinyTapeout* template has the following inputs and outputs:
```verilog
input  wire [7:0] ui_in,    // Dedicated inputs
output wire [7:0] uo_out,   // Dedicated outputs
input  wire [7:0] uio_in,   // IOs: Input path
output wire [7:0] uio_out,  // IOs: Output path
output wire [7:0] uio_oe,   // IOs: Enable path (active high: 0=input, 1=output)
input  wire       ena,      // always 1 when the design is powered, so you can ignore it
input  wire       clk,      // clock
input  wire       rst_n     // reset_n - low to reset
```

Here the description to all the pins:
- `ui_in`: 8 bit input
- `ui_out`: 8 bit output
- `uio_in`: 8 bit I/O pins that will be used as inputs
- `uio_out`: 8 bit I/O pins that will be used as outputs
- `uio_oe`: 8 bit pins that decide which pins of the `uio_in` and the `uio_out` are inputs or outputs
- `ena`: ASIC enable, is always 1 when the design is powered
- `clk`: The clock
- `rst_n`: Reset, active low

The ASILUC uses the `ui_in` pins to take in input the numbers to elaborate, the `ui_out` for the result of the operation (a 16 bit number split in 2), the `uio_oe` fixed at `00001111` to have available to `uio_in` the highest 4 bits for the command input and to `uio_out` the lowest 4 bits for the status output.

The chip can be syncronous or asyncronous.
It's recommanded to made it syncronous if the ASIC made complex operations.
